This repository contains Python programs prepared for the Python ABL (Activity-Based Learning) work. The programs demonstrate basic Python concepts through practical problem statements and coding exercises.

- `case1.py` to `case10.py` – Python program files.

## How to Run the Programs

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run a program using:

```bash
python case1.py
```

Replace `case1.py` with the name of the program you want to execute.
